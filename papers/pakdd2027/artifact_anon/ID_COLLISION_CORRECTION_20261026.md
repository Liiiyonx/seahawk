# 基准 id 冲突事故与更正（2026-10-26）

## 事故

`build_retrieval_benchmark.py` 生成的题目 id 不含资产/链路信息（如所有
`OD-SEA-E-*` 资产的标题型题共用 `single-OD-SEA-E-0`），306 题只有 **22 个唯一 id**，
其中 283 处"同 id 不同题不同金标"冲突。一切按 id 键控的逐题分析被静默污染：

- `results[item_id]` 同组互相覆盖（后写者胜，评测脚本还是双线程，胜者不确定）；
- 指标计算把"别的题的检索排序"配到"本题的金标"上，**系统性压低了全部数字**；
- v1（190题/15资产）与 v2（306题/27资产）两轮的所有已登记数字均受影响。

## 修复（全部可复现）

1. `scripts/fix_benchmark_ids.py`：基准 id 追加出现序号使其唯一（题目/金标字节不变）。
   原始冲突版保留为 `benchmark_ids_collided_20261026.json`。
2. `scripts/run_retrieval_eval.py` 重跑（嵌入/重排缓存全热，分钟级）。
3. `scripts/run_bm25_ablation.py`、`scripts/compute_significance.py`、
   `scripts/run_router_eval.py`（新增：两系统规则路由器）全部重跑。
4. 受污染旧产物保留：`eval_306_snapshot_collided.json`、`bm25_ablation_collided.json`、
   `eval_190_v1_collided.json`。

## 更正前后对照（hit@5，冻结快照）

| 配置 | 标题型 旧→新 | 实体型 旧→新 | 多跳 旧→新 |
| --- | --- | --- | --- |
| BM25（无图） | .457→**1.000** | .180→**.840** | .075→**.950** |
| 词法+图（生产） | .432→**.852** | .310→**.930** | .475→**.983** |
| 稠密+精排 | .222→**.481** | .190→**.450** | .458→**.725** |
| RRF 混合 | .432→**1.000** | .380→**.860** | .458→**.983** |
| 混合v3标题加权 | .444→**1.000** | .410→**.870** | .458→**.983** |

新增结论（更正后成立）：
- **无单一配置全能**：BM25 称霸标题型（hit@1 .901），图扩展称霸实体/多跳；
  稠密+精排全题型显著最差。
- **两系统规则路由器**（标题覆盖≥0.5→BM25，其余→图扩展）显著优于所有单一配置
  （p<0.005），与逐题型最优 oracle 无显著差异（p=0.10）。
- **拒答**：无任何配置分数可分（词法零分地板重叠 / BM25 反转 / 稠密低尾重叠）。
  旧版"词法可分"结论作废。
