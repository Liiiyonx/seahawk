## 三、口径声明

1. 本表不为演示资产伪造标准条文；凡未取得官方原文、文号或条款的规范，
   一律写“待获取真实规范条款”。
2. 对外表述中，标准码只能表示“内部演示数据使用的分类/流程标识”或“待对接
   的真实规范”，不得写成“已对接 XX 规范第 X 条”。
3. 华为材料引用本表时，必须同时说明真实规范条款尚未取得，不能把演示数据
   的业务分类冒充行业标准。
