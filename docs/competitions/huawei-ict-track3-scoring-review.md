   2026-09-30 在本地官方源码部署中补齐一次真实 LLM 完整 Skill 问答

   并留存 Nexent 控制台截图与完整 SSE/工具轨迹。

   托管平台已创建智能体并配置 DeepSeek 模型（R-NX-06），编辑页明确提示公网环境
   不支持 Skill，平台限制已留证。R-KN-04 是本地知识域前端轨迹；R-NX-09 已
   补齐**本地 Nexent 控制台**的完整问答截图与轨迹，托管平台内截图仍缺。
   2026-09-30 已建好私网环境与网关，但华为云账号欠费导致“创建 Target”按钮禁用

   充值后的 Target 字段、VPC endpoint 方案、截图清单和失败排查已固化为
   `huawei-agentarts-vpc-target-runbook.md`；完成后登记 R-NX-08，不覆盖 R-NX-07。
3. 业务与算法两层缺“真”：演示数据不是真实脱敏行业数据；本体半自动构建
   有工程闭环与软件内部效率评测，但算法本身仍是确定性规则，金标也是
   内部 fixture，不是行业标准答案；公开开放数据替代评测（R-OD-01）已补齐，

首次具备“LLM 模型 + 21 工具 + 绑定 5 Skill（本次问题实际加载 4 个）

**不是华为托管平台内验收**，也不是真实脱敏数据评测，不能按两项均已补齐的
顶格区间报分。

剩余清单（托管平台内完整 Skill 问答截图、真实脱敏行业数据评测）全部

### 2.3 算法创新性 / 低资源半自动本体构建（25%）

**已有证据**

- 低资源半自动构建：从指定资产版本抽取候选节点与关系，候选默认未审核，
  人工审核通过后才发布；不依赖标注数据，不冒充训练模型。
- 本体持续动态更新：本体版本可继承父版本，保留 `standard_codes` 实现
  与行业规范/标准体系对齐；R-KN-01 已演示一次版本追加后的再抽取、审核、
  发布。
- 确定性可解释：抽取基于词频/标题权重/共现，候选带来源资产版本和引用片段。
- 效率评测：R-KN-02 在 12 份内部合成治理语料上对比当前实现与朴素频次基线，
  输出候选短语占比、精确命中率、top-100 术语覆盖、候选关系与抽取耗时。
- 增量维护对比：R-KN-03 在追加 1 个资产版本后对比全量重抽（3.364ms）与
  增量追加（1.116ms），时间节省 66.8%，并说明候选/关系差异；为 E1 软件
  内部相对对比。
- 公开开放语料评测：R-OD-01 在生态环境部 8 份公开通知上完成候选抽取与
  基线对比，来源可追溯；为 E1 替代证据，不是真实脱敏行业数据评测。
- 标准体系映射：`docs/competitions/standard-code-mapping.md` 已把
  `standard_codes` 落到“标准码 → 规范 → 条款 → 来源与状态”的映射表，
  未取得原文的规范明确写“待获取真实规范条款”。

**失分点**

1. 算法本身是词频 + 共现规则，没有差异化创新点；评测证明的是候选结构更短、
   精确命中更高，不等于算法原创性。
2. 评测金标是内部 fixture，不是行业标准答案；top-20 短短语覆盖 40% 低于
   基线 60%，不能据此宣称识别更准。
3. 持续更新已补增量维护对比（R-KN-03），但语料为内部合成文本，增量语义
   尚未在真实行业语料上复核。
4. 标准体系映射表已建立，但真实规范条款尚未取得，只能表达“待对接”。

**预估得分**：19-21 / 25。工程闭环诚实且完整，效率评测、增量维护对比与
公开开放语料评测已补上量化证据，但“算法创新性”与真实规范对齐仍待外部输入。

   关系（R-NX-04）；同日把 Agent 升到发布版本 4、接入 DeepSeek
   `deepseek-v4-pro`，跑通一次完整 LLM Skill 问答（R-NX-09：HTTP 200、
   8 步、31 次工具调用、2,777 字回答、Nexent 控制台截图）。②华为托管
   平台（AgentArts）已完成 MCP 注册、21 工具加载、公网端点真实只读调用
   （R-NX-05）、Agent 创建与 DeepSeek 模型配置（R-NX-06）以及 5 个 Skill
   导入。③**托管平台内完整 Skill 问答尚未跑通**：公网环境不支持 Skill，
   切私网后因账号欠费“创建 Target”禁用（Target 0/10，R-NX-07 blocked），
   解除欠费后才能绑定 Target 并验收。R-NX-09 是本地 Nexent 验收，
   R-KN-04 是本地知识域前端轨迹，二者都不冒充托管平台截图。
   充值后的 Target 字段、VPC endpoint 方案和截图清单已写入
   `huawei-agentarts-vpc-target-runbook.md`；完成前不把该手册当作验收。
2. “这个本体抽取和普通关键词抽取有什么区别？”
   → 确定性词频+共现候选算法；R-KN-02 显示 top-20 候选全部为短语节点、
   精确命中 35%（基线 5%）、top-100 覆盖 100%（基线 95%），并输出带来源
   证据的关系；但 top-20 短短语覆盖 40% 低于基线 60%，不宣称识别更准。
3. “业务价值有没有量化指标？”
   → 已有 E1 测算框架（设计文档 8.3：检索、决策固化、派单、本体维护四环节
   对照表），数字为 E0-E2 测算/演示口径；真实运营收益待 E3 数据替换，不能
   把测算写成已实现收益。
4. “真实脱敏行业数据评测完成了吗？”
   → 没有；当前仅完成公开开放数据替代评测（R-OD-01，8 份生态环境部公开
   通知，E1），材料中明确标注“非真实脱敏行业数据”，不冒充赛题附加分要求
   的真实脱敏数据集。
5. “感知精度是多少？”
   → `not_evaluated`；76% 是时序链路误报抑制率，不是识别精度。
6. “昇腾/ModelArts/鲲鹏跑过吗？”
   → 没有；三条均为架构/配置就绪、待验证。
