## 二、参赛资格自查（官方硬条件，报名前逐条确认）

- [ ] 主要申报人年龄 ≤55 岁（1971-01-01 以后出生）
- [ ] 项目无国内外知识产权纠纷；海洋科创项目须证明「完全自主知识产权」
- [ ] 若已设企业：申报人为主要创办人/主要股东，或核心技术持有人且技术持股
- [ ] 申报人未获国家级或福建省级人才计划项目支持
- [ ] 申报人未获福建省委人才办主办的创新创业赛事三等奖（铜奖）及以上
- [ ] 学生项目须配 1 名指导老师
- [ ] 主要申报人只申报 1 个项目；承诺全程参与
- [ ] 与华为 ICT 赛的重复参赛/材料复用合规性：需向两主办方确认

## 五、最大加分项与最大扣分项

**加分（按边际收益排序）**
1. 「岸基先行」落地路线：15 天内就能在连江做 1 个真实点位/准真实演示，是创业赛最有效的可信度信号。
2. 工程可验证性：1061 测试、E2 集成、证据分级纪律，在县级赛里是稀缺的「认真」信号，答辩可现场复现。
3. 22 万落地补助政策匹配：项目天然为连江设计，讲清「获奖→落地→就业/税收/治理成效」链条。

**扣分（按严重性排序）**
1. 零真实外部证据（访谈/询价/意向/现场）——创业赛最大硬伤。
2. 机器人无实物 + 感知精度 `not_evaluated`——会被问「船呢？准吗？」。
3. 团队与指导老师不完整——踩官方学生项目条件。
4. 知识产权无证书——踩「完全自主知识产权」举证要求。
5. 试点期单吨成本高于人工，经济性故事需要说明「满负荷 250 元/吨」只是 E0 内部测算且未验证（E-09），不能当作真实成本。

## 七、与华为 ICT 赛道三的差异化判断

| 维度 | 华为 ICT 赛道三 | 连江海洋科创赛道 |
| --- | --- | --- |
| 评审重心 | 技术、平台适配、创新性、可复现 | 落地、创业、产业带动、社会价值 |
| 对手水平 | 全国高校/企业开发者，技术竞争强 | 县级赛，实业与科研团队混合 |
| 当前弱项 | 托管平台 Skill 链路未通、开源未发布 | 零商业证据、无实物、无团队呈现 |
| 补分动作 | 打通 AgentArts 私网链路 + 发布开源 + 答辩 | 访谈/询价/意向/现场 + 团队 + 软著 |
| 独立评分 | 70.5/100（补齐后 ≈86.5） | 62/100（补齐后 ≈74） |
| 结论 | 同一项目在技术口径下明显更强；创业口径下证据缺口被放大 |

两赛材料复用边界：技术架构、证据链、演示系统可复用；「国奖候选」「平台适配」等华为口径表述不得直接搬进连江材料；连江材料应重写为「连江落地叙事」。
