## 0. 门禁逻辑（先读再执行）

- 证据门禁 = 每项能力在试点前必须持有的最小证据集。缺一项，就缺一类对外宣称权。
- 证据必须是**真实获取**的（官方原文、访谈记录、询价单、现场记录、试点数据）；「规划了、打算去获取」不等于证据。
- 每项证据完成后，回填到《商业证据台账.md》（等级上调、复核状态更新），并勾选本清单。
- 内部软件证据已形成 1061 项测试、Agent E1/E2 轨迹与真实状态集成验收、契约自证等可复现材料，不在本清单；本清单只跟踪必须从外部真实获取、用于进入试点的证据。

## 5. 禁止宣称条款（与计划书 §1/§2.2 一致）

1. 未取得 PR-D3 现场验证记录前，禁止宣称「已完成现场验证 / 真实海域验证」（E3）。
2. 未取得 PR-C2 意向与 PR-C1 预算路径前，禁止宣称「客户 / 订单 / 试点已落实」。
3. 未取得合同、回款、验收单前，禁止使用「已成交 / 已签约 / 已回款 / 已部署 / 客户付费」措辞（台账 §8）。
4. 未取得 PR-B1/B2 报价前，单台成本只能表述为「测算价 15,200 元（E0 测算）」，不得写成可实现成本。
5. 所有对外商业数字必须带《商业证据台账》编号；无编号数字一律不上台面。
