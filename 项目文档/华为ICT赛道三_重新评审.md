> 评分口径：初赛技术评分 100 分制，四项各 25 分
> 证据纪律：已实证项与 `not_evaluated` 项严格分开；本地验收、公网调用、准备手册均不冒充华为托管平台完整验收

## 一、结论

当前初赛材料预估 **74 / 100**。整体属于“省赛区有竞争力，但距头部队伍仍有明确差距”的水平。
最强的是智能体编排与 MCP/Skill 集成，最弱的是“平台内完整可运行 + 真实数据评测”这条评委最看重的证据线。

核心判断：项目在工程完成度、证据纪律和系统闭环上明显高于多数学生作品，
但“真实”不足：真实脱敏行业数据没有拿到，华为 AgentArts 托管平台内完整 Skill 问答尚未跑通，
多跳推理缺少一个真实实例。这三项恰是赛道三区分头部队伍的硬指标。

## 二、四项分项评分

### 2.1 智能体编排与 MCP/Skill 深度集成（22 / 25）

**已实证**
- 21 个 MCP 只读工具常驻，11 个写入工具按开关注册，共 32 个，协议实现完整。
- 5 个 SKILL.md 工作流模板已导入，R-NX-09 真实问答中 `read_skill_md` 实际加载 4 个 Skill。
- 本地 Nexent v2.6.1 完整 LLM 问答已跑通：DeepSeek、8 步、31 次工具调用、13 个唯一工具、无 run error、2,777 字带证据链回答。
- 华为 AgentArts 已完成 MCP 注册、21 工具加载、Agent 创建与模型配置；2026-10-01 网关工具调试页完成一次真实 MCP `POST` 与 `agent_runtime_status` 工具调用，返回 `tools_registered=6`、`state=idle`、`rule_mode=true`。

**扣分**
- 上述网关调用是单工具协议验收，不是平台内自然语言 Skill 问答；`platform_qa_completed: false`、`live_skill_qa_completed: false`。
- Agent 当前仍绑定公网环境，私网 Target 虽 online，但完整“私网环境 + 绑 Agent + 平台内问答”尚未闭环。

### 2.2 知识图谱本体构建、动态更新与标准对齐（18 / 25）

**已实证**
- R-KN-02：12 份内部合成治理语料，top-20 精确命中 11/20（55%，基线 5%），top-100 术语覆盖 100%。
- R-KN-03：增量追加相比全量重抽节省 63.19%（4.387ms vs 1.615ms）。
- 本体版本继承、`standard_codes` 标准体系映射表、候选审核后发布机制完整。

**扣分**
- 算法本质是词频 + 共现确定性规则，工程性强但算法原创性弱。
- 评测金标是内部 fixture，不是行业标准答案；top-20 关系仅命中 1/7（14.29%），关系能力明显不足。
- 标准体系映射表多数真实规范条款“待获取”，标准对齐仍停留在映射设计层。

### 2.3 检索-推理双驱动、跨文档多跳与决策溯源（19 / 25）

**已实证**
- “问题 → 检索 → 决策 → 证据链”链路真实可运行，证据带资产版本、节点、关系、引用。
- R-KN-04 展示本体图检索 4 条命中、4 条有序证据链，前端可查。
- R-NX-09 展示 LLM 在证据不足时明确输出“不得自动派单”并列出证据缺口，不伪造结论。

**扣分**
- R-KN-04 是 `hop_count=0` 的直接资产引用检索，不是真正多跳推理实例。
- 跨文档多跳依赖的路径级输出缺少一次可复现的真实评测记录。

### 2.4 Nexent 平台可运行性、真实数据评测与可复用 Skill（15 / 25）

**已实证**
- 本地 Nexent 官方源码部署完整问答可运行、可回放，截图与 SSE/工具轨迹齐全。
- R-MG-01：海洋/医疗/政务三领域模板迁移验证，检索命中 3/3（演示级）。
- R-OD-01：8 份生态环境部公开通知替代评测，来源 URL 与 SHA256 可追溯。

**扣分**
- 华为 AgentArts 托管平台内完整 Skill 问答未完成，平台 run id 为 `not_evaluated`。
- 真实脱敏行业数据未取得；R-OD-01 明确是公开数据替代，不满足赛题附加分要求的真实数据评测。
- 无交互演示录屏；感知精度保持 `not_evaluated`，76% 仅代表时序链路误报抑制率。

**总分：74 / 100**（22 + 18 + 19 + 15）

## 三、晋级概率（全国总决赛）

按“初赛 → 区域/省赛 → 全国总决赛”链路做独立推断。官方晋级名额未公开，以下为评委经验推断，置信度中低。

- **当前状态晋级全国总决赛概率：12% – 18%**。
  依据：材料完整性较好、工程证据在同级中稀缺，可支撑通过初赛；
  但平台内完整 QA 与真实脱敏数据两项硬证据缺失，若头部队伍普遍完成，本项目会被系统性压低。
- **补齐托管平台完整 Skill 问答 + 真实脱敏数据评测 + 一个真实多跳案例后：25% – 35%**。
  补齐后四项均达到“有真实验证”的基准线，进入头部竞争区间。
- 明确边界：12% – 18% 是“能进入全国总决赛”的综合概率，不是“进入省赛区”概率；
  若只评估通过初赛，当前可到 60% 左右，但初赛通过不等于国赛概率。
