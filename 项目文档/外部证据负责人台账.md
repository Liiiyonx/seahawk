## 4. 每周更新纪律

每个证据条目每周只允许处于以下受控状态之一：

- 待获取：尚未发出联系或检索。
- 已联系：已联系对方或已定位官方来源，但尚未拿到材料。
- 材料待补：口头信息或页面已看到，但原件、文号、有效期或授权不完整。
- 待复核：原件已到手，等待独立复核。
- 已复核：总控核对原件、确认口径与等级。
- 已归档：已进入证据登记和商业台账。
- 已失效：报价过期、链接失效或授权撤回。

状态更新必须同时写日期、负责人和材料编号；没有材料编号不得从“待获取”直接跳到“已复核”。

## 5. 复核检查表

每次周会按以下问题逐项检查：

- [ ] 责任人是否明确到人，而不是“团队”或“待定”。
- [ ] 目标日期是否明确，延期是否给出新日期。
- [ ] 是否留下了联系记录、检索记录或现场记录。
- [ ] 原件是否可以由第三人打开并核对。
- [ ] 证据等级是否严格按原件判定。
- [ ] 是否明确哪些结论仍不能对外使用。
- [ ] 是否已登记到 `docs/evidence-inbox/`。
- [ ] 是否已更新《商业证据台账.md》和 `docs/product-readiness.md`。

## 6. 升级门槛

### E3 起点

- 访谈：真实对象、日期、授权、记录和关键引述齐全。
- 询价：真实供应商、日期、有效期、含税口径与原始报价齐全。
- 政策：发布机关原文、文号或页面证据、关键段摘录齐全。
- 现场：真实设备运行、场景边界、原始日志和现场记录齐全。

### E4

- 合同、订单、回款、验收报告或复购凭证之一，且能核对真实对象与金额/结论。

任何口头承诺、微信截图、未盖章方案、演示邀请或计划书承诺，都不能单独升级为 E4。
