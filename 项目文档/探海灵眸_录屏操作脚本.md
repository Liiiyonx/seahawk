# 探海灵眸 · 演示视频录屏操作脚本（执行版）

> **这是给操作者的脚本，不是给剪辑的。** 拿着它坐在电脑前，从上往下做，每一步写清了点哪里、等多久、看到什么才算成功。
> 录屏**全程不用说话**——旁白后期按剪辑脚本配，你只管把操作录干净。
> 预计总录制时长：**10~12 分钟**（含账号切换等待，剪辑后有效素材约 8 分钟）。

---

## 一、录前准备（约 10 分钟，做一次）

### 1. 服务自检（顺序执行，全过再录）

| # | 命令 | 期望 |
|---|---|---|
| ① | `make check-demo-approval` | 三环全绿、退出码 0 |
| ② | `make demo-approval-up` | 容器起来 |
| ③ | `make bootstrap-demo-users` | 4 个账号 created/updated |
| ④ | `make demo-approval-check` | `require_approval_for_write = True` |
| ⑤ | `docker logs seasight-backend --since 2m \| grep 后台任务` | 「后台任务已按配置关闭」 |

### 2. 事件状态复核（两个事件都应 `new`、待审批 0）

```bash
docker exec seasight-postgres psql -U seasight -d seasight -c \
  "SELECT event_id,status FROM t_event WHERE event_id IN ('evt_demo_0015','evt_demo_0016');"
```

> 若不是 `new`，先跑本文末尾「录完之后」的重置 SQL，再回来。

### 3. OBS 设置

- 画布/输出：**1920×1080、30fps**；录制格式 MKV（录完可无损转 MP4）。
- 录屏来源：**采集浏览器窗口**（不要全屏采集，避免 OBS 自己入镜）。

### 4. 浏览器准备

- 窗口**拉宽到接近全屏**（嵌入式面板窄于 1280 顶栏会折行）。
- 只留一个标签页，收藏栏隐藏（F11 全屏更干净，可选）。
- 鼠标灵敏度调低一档——录屏里鼠标要走得稳。

### 5. 账号准备

- 主电脑：当前登出状态，停在登录页。
- **手机（加分项）**：提前登好 `approver / approver123456` 挂着，段 2 录到批准环节时用手机拍 10 秒实拍（「第二个人放行」的论据）。

## 二、录制总规划：4 段，分段存 4 个文件

| 段 | 内容 | 预计时长 | 对应剪辑镜头 |
|---|---|---|---|
| 1 | 平台总览（大屏） | 约 1 分钟 | 剪辑脚本镜头 7 |
| 2 | 智能体审批流（A1~A7） | 约 3.5 分钟 | 镜头 9~16 |
| 3 | 研判门禁（B1~B4） | 约 2.5 分钟 | 镜头 18~22 |
| 4 | 机械臂闭环（C1~C5） | 约 2.5 分钟 | 镜头 24~26、28 |

> **每段录完按 OBS 停止键**，产出独立文件，命名：`段1_大屏.mkv`、`段2_审批流.mkv`、`段3_研判门禁.mkv`、`段4_机械臂.mkv`。
> 一段失败只重录那一段，不用从头来。

## 四、录屏节奏铁律（录废 90% 都是因为没守这些）

1. **每次点击前停 1 秒，点击后停 2~3 秒**——给剪辑留下刀点。
2. 鼠标**匀速移动**，不要甩；不点的手离开鼠标。
3. **全程不说话、不咳嗽**；键盘声尽量避免（输事件 ID 时敲键盘没关系）。
4. 大屏段（段 1）**60 秒内结束**——视频流停留久了会冻结，冻住只能重录。
5. 轨迹回放**永远不快进**（1.5s/步是设计好的节奏）。
6. 每个截图上有的关键状态（等待审批、无新工单、ACK、安全终止）出现时，**多停几秒**——脚本里标了「停 Xs」的就是这些点。
7. 失误了不要说"啊"也不要倒回去，**停 3 秒重做该步**，剪辑能剪掉。

## 五、录完之后（5 分钟）

1. **重置事件**（还给下次录制/演示）：

```bash
docker exec seasight-postgres psql -U seasight -d seasight -v ON_ERROR_STOP=1 -c "
BEGIN;
DELETE FROM t_task_ack WHERE task_id IN (
  SELECT task_id FROM t_task
   WHERE event_id IN ('evt_demo_0015','evt_demo_0016') AND task_id NOT LIKE 'tsk_demo_%');
DELETE FROM t_track WHERE task_id IN (
  SELECT task_id FROM t_task
   WHERE event_id IN ('evt_demo_0015','evt_demo_0016') AND task_id NOT LIKE 'tsk_demo_%');
DELETE FROM t_task
 WHERE event_id IN ('evt_demo_0015','evt_demo_0016') AND task_id NOT LIKE 'tsk_demo_%';
UPDATE t_event SET status='new' WHERE event_id IN ('evt_demo_0015','evt_demo_0016');
COMMIT;"
```

2. **重置机器人仓容**（大量工单会把垃圾仓撑满 → 派单报「无可用机器人」；录屏前发现镜头 C 建不了单就跑这个）：

```bash
docker exec seasight-postgres psql -U seasight -d seasight -c "
UPDATE t_device SET meta = jsonb_set(jsonb_set(jsonb_set(meta,'{bins,foam}','0.05'),'{bins,mixed}','0.03'),'{bins,plastic}','0.04'),
  last_heartbeat = now(), status='online' WHERE device_id IN ('RBT-001','RBT-002');"
```

2. 快速回放 4 个文件：检查画质、听有没有杂音、确认关键帧（2-6 等待审批、2-8 无工单、2-12 新工单、3-7 安全终止、4-6 ACK）都在。
3. （可选）MKV 转 MP4：`ffmpeg -i 段2_审批流.mkv -c copy 段2_审批流.mp4`
4. 4 个文件放进 `演示视频\05_录屏素材\`，手机实拍（如有）也放进去——剪辑队友按剪辑脚本 V2 的镜头表对位使用，**录屏素材替换原 A/B/C 截图**（有动态录屏就优先用录屏，截图退为备用）。
