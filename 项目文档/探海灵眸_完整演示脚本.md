## 1. 录前准备（约 10 分钟，做一次）

### 1.1 服务自检（30 秒）

```powershell
docker ps --format "{{.Names}} | {{.Status}}"     # seasight-* 全部 Up
curl.exe -s http://localhost:18000/health          # redis/mqtt/database 三项 ok
```

浏览器打开 `http://localhost:5173`，停在**登录页未登录**状态。

### 1.2 一键刷新演示数据（30 秒）

```powershell
docker exec seasight-postgres psql -U seasight -d seasight -f /sql/refresh_demo_data.sql
```

期望末尾 NOTICE：`今日事件 14 条 | 24h 待处理 7 条 | 演示活跃工单 4 条 | 演示已完成 5 条 | 轨迹 50 点 | ACK 7 条`。

### 1.3 锚点校验（30 秒）

```powershell
docker exec seasight-postgres psql -U seasight -d seasight -c "SELECT event_id,status FROM t_event WHERE event_id IN ('evt_demo_0015','evt_demo_0016','evt_CAM-MABI-01_900001');"
docker exec seasight-postgres psql -U seasight -d seasight -c "SELECT task_id,status FROM t_task WHERE task_id IN ('tsk_demo_1000','tsk_demo_1001','tsk_demo_1003');"
```

期望：三个事件都是 `new`；工单 `1000=pending / 1001=assigned / 1003=collecting`。

### 1.4 把两个"旧事件"时间刷到近期（建议做）

B 镜头用的 `evt_CAM-MABI-01_900001`（原时间 10-08）与 C 镜头用的 `evt_demo_0016`（原时间 10-05）在默认「近 24 小时」筛选里看不到；刷新一下录起来更顺：

```powershell
docker exec seasight-postgres psql -U seasight -d seasight -c "UPDATE t_event SET event_time = now() - interval '3 hours' WHERE event_id IN ('evt_CAM-MABI-01_900001','evt_demo_0016');"
```

> 不做也能录：B 镜头把事件中心时间筛选切「近 3 天」，C 镜头切「近 7 天」即可。

### 1.5 OBS 与浏览器

- OBS：**1920×1080 / 30fps**，来源选**采集浏览器窗口**（不要全屏采集）。
- 浏览器窗口拉宽到接近全屏（嵌页面板窄于 1280 顶栏会折行）；隐藏收藏栏；只留一个标签页。

### 1.6 账号准备

- 四个测试账号都在登录页「测试账号」面板一键填入：**admin / operator / approver / viewer**。
- 加分：手机提前登录 approver，拍 10 秒"第二个人放行"实拍（后期画中画）。
