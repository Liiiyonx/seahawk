# 机械臂仿真台接入准备

> 目标：把平台「工单执行仿真」页里的前端 3D 机械臂动画，换成跳转到
> ArmPiFPV 树莓派自带仿真台 / 上位机；地图视图保留，真机到货后只填一个
> 跳转地址即可演示。

## 一、当前改动

- `frontend/src/components/ArmSimConsole.vue`：新增「仿真台」入口面板，展示
  跳转目标、真机热点、登录账号，并提供「打开仿真台」和「复制连接信息」。
- `frontend/src/views/SimulationView.vue`：视图切换从「地图 / 3D 作业」改为
  「地图 / 仿真台」，默认进入仿真台；3D 动画代码保留在
  `frontend/src/components/SimulationScene.vue` 与
  `frontend/src/utils/robotArmScene.js`，已停用，不参与页面加载。

## 二、跳转地址配置

在 `frontend/.env.local` 配置：

```ini
VITE_ARM_CONSOLE_URL=<真机仿真台跳转地址>
VITE_ARM_CONSOLE_LABEL=ArmPiFPV 仿真台
```

跳转地址建议二选一：

1. NoMachine 远程桌面连接地址：真机树莓派开机后，电脑连上 `HW` 开头热点，
   用 NoMachine 打开 `192.168.149.1`（账号 `ubuntu`，密码 `hiwonder`），
   进入桌面后启动 ArmPiFPV 上位机。
2. 若真机上启用了网页控制台 / Web 上位机，直接填对应的
   `http://<树莓派IP>:<端口>`。

未配置地址时，按钮保持禁用并提示「待接入真机」，不会假装已连接。

## 三、真机到货后的联调顺序

1. 树莓派上电，确认扩展板 LED 从常亮变为每 2 秒闪烁一次。
2. 电脑连接树莓派热点（`HW` 开头）或同一局域网，安装资料包内的
   `nomachine_8.4.2_10_x64.exe`，连接 `192.168.149.1`。
3. 在树莓派桌面打开 ArmPiFPV 上位机，先用动作编辑录一组示教姿态，再与
   `edge/arm_bridge/tools/teach_hiwonder_sequence.py` 的示教产物核对。
4. 把平台入口地址填进 `frontend/.env.local`，重新 `npm run dev` 或重新构建，
   仿真页点「打开仿真台」即可跳转。

## 四、口径红线

- 真机 + 仿真海面 / 受控实验统一标 **E2**，不写成真实海域验收。
- 感知精度保持 `not_evaluated`；「仿真台能打开」不等于「识别准了」。
- ArmPiFPV 上位机 / MoveIt 是厂商自带的控制与仿真环境，不是本项目的感知或
  决策证据；演示时明确区分「平台派单链路」和「厂商仿真台」。
- 资料包内没有 MoveIt 的 Ubuntu 镜像与 ArmPiFPV Python 源码，逆运动学仍等
  真机后从树莓派 `/home/ubuntu/armpi_fpv/...` 复制。
